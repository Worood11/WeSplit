# WeSplit

Project 1 of the [100 Days of SwiftUI](https://www.hackingwithswift.com/100/swiftui) challenge—a simple bill-splitting app built with Swift and SwiftUI to calculate check totals, tip percentages, and per-person amounts.

<img width="300" alt="WeSplit App Screenshot" src="https://github.com/user-attachments/assets/51f2c979-23d4-49f9-8909-d63952cf8b07" />

## 🛠️ Concepts Covered
* `@State` & `@FocusState` property wrappers
* `Form`, `Section`, and `Picker` views
* Localized currency formatting
